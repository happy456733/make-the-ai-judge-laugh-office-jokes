A single original one-line joke about office life, written by a deterministic Node program to `entry.txt` for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes one line — 82 characters, about office life — to `out/entry.txt` (or `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is unset). Node 22.18+, TypeScript, standard library only, no network requests, no reads outside this repository.
